01
THE BASICS

What is Git?

Git គឺជា Distributed Version Control System (DVCS) ដែលជួយតាមដានការផ្លាស់ប្ដូររបស់ Source Code និងរក្សាទុកប្រវត្តិនៃ Project។

និយាយឱ្យងាយយល់៖ Git ដូចជាប្រព័ន្ធ Save ប្រវត្តិការងាររបស់អ្នក។ ប្រសិនបើកែ Code ខុស អ្នកអាចពិនិត្យ ឬត្រឡប់ទៅ Version មុនបាន។

Why do developers use Git?

🕘Track historyតាមដានការកែប្រែ Code
↩️Restore changesអាចត្រឡប់ទៅ Version ចាស់
👥Work togetherសហការជាមួយ Developer ផ្សេងៗ
🌿Develop safelyបង្កើត Branch សម្រាប់ Feature ថ្មី
02
CORE CONCEPT

Version Control System (VCS)

VCS គឺជាប្រព័ន្ធសម្រាប់គ្រប់គ្រង និងតាមដាន Version ផ្សេងៗរបស់ File ឬ Project។

TypeExplanation
Local VCSរក្សាប្រវត្តិនៅក្នុង Computer មួយ។
Centralized VCSមាន Server កណ្ដាលសម្រាប់រក្សាទុក Version។
Distributed VCSអ្នកអភិវឌ្ឍន៍ម្នាក់ៗមាន Repository ចម្លងពេញលេញ។ Git ជាប្រភេទនេះ។
03
IMPORTANT DIFFERENCE

Git vs GitHub

Git និង GitHub មានទំនាក់ទំនងគ្នា ប៉ុន្តែមិនមែនជារបស់តែមួយទេ។

◆

Git

Version Control Tool

  • គ្រប់គ្រង Version
  • ប្រើក្នុង Local Computer
  • Commit និង Branch
◉

GitHub

Online Hosting Platform

  • រក្សាទុក Repository Online
  • ចែករំលែក Code
  • Pull Request និង Collaboration
Remember: អ្នកអាចប្រើ Git ដោយមិនចាំបាច់មាន GitHub។ GitHub ប្រើ Git ដើម្បីជួយសហការតាម Internet។
04
VOCABULARY

Important Git terminology

Repository (Repo)

កន្លែងផ្ទុក Project និង Commit History។

Commit

កំណត់ត្រានៃការផ្លាស់ប្ដូរ Code មួយ។

Branch

សាខាដាច់ដោយឡែកសម្រាប់អភិវឌ្ឍ Feature។

Merge

បញ្ចូលការផ្លាស់ប្ដូរពី Branch មួយទៅមួយទៀត។

Clone

ចម្លង Repository ពី Remote មក Local។

Push

ផ្ញើ Commit ពី Local ទៅ Remote។

Pull

ទាញ និងបញ្ចូលការផ្លាស់ប្ដូរពី Remote។

Conflict

ការប៉ះទង្គិចគ្នានៃការកែប្រែ Code។

06
PRACTICE TIME

Basic Git commands

សាកល្បង Commands ខាងក្រោមក្នុង Terminal។ ចុច Copy ដើម្បីចម្លង Command។

Check Git versionពិនិត្យថាបានដំឡើង Git ឬនៅgit --version
Set your nameកំណត់ឈ្មោះសម្រាប់ Commitgit config --global user.name "Your Name"
Initialize repositoryបង្កើត Git Repository ថ្មីgit init
Check statusមើលស្ថានភាព Filegit status
Add all changesបន្ថែមការផ្លាស់ប្ដូរទៅ Staging Areagit add .
Save a commitរក្សាទុកការផ្លាស់ប្ដូរgit commit -m "Initial commit"
View commit historyមើលប្រវត្តិ Commitgit log --oneline
07
WORK IN PARALLEL

Branching and merging

Branch អនុញ្ញាតឱ្យអ្នកអភិវឌ្ឍ Feature ថ្មី ដោយមិនប៉ះពាល់ Branch សំខាន់ភ្លាមៗ។

main
feature-login
↗ Merge back into main
git branch feature-login git switch feature-login # Make your changes git add . git commit -m "Add login feature" git switch main git merge feature-login

COLLABORATION

Working with GitHub

CommandMeaning
git clone URLចម្លង Remote Repository មក Local។
git remote add origin URLភ្ជាប់ Local ទៅ Remote Repository។
git pushផ្ញើ Commit ទៅ Remote។
git pullទាញ និងបញ្ចូលការផ្លាស់ប្ដូរថ្មី។
git fetchទាញព័ត៌មាន Remote ដោយមិនបញ្ចូលទៅ Branch បច្ចុប្បន្ន។
Team workflow: បង្កើត Branch → សរសេរ Code → Commit → Push → បង្កើត Pull Request → ពិនិត្យ Code → Merge។
